# GreenSpark Tech – Network Design Project
# Tool: 
- Cisco Packet Tracer

# Overview

This project involves designing and implementing a network infrastructure for GreenSpark Tech, an innovative startup focused on developing eco-friendly app solutions. The goal is to create an efficient, scalable, and secure network that supports communication and collaboration across five key departments.

# Departments

1. Innovation & Development
2. Marketing & Outreach
3. Sales & Customer Engagement
4. Tech Support & Security
5. Operations & Sustainability

Each department has distinct network requirements that are addressed through proper IP addressing, VLAN configuration, and inter-VLAN routing.

# Objectives

- Design a logical and efficient IP addressing scheme using VLSM
- Configure VLANs for departmental segmentation
- Set up inter-VLAN routing for secure communication
- Implement switch and router configurations via CLI
- Ensure network scalability and performance optimization

# Key Concepts Used

- Variable Length Subnet Masking (VLSM)
- VLAN Configuration & Trunking
- Router-on-a-Stick Inter-VLAN Routing
- IP Addressing & Network Design
- Network Simulation in Cisco Packet Tracer
  
# Tools & Technologies

- Cisco Packet Tracer
- Cisco CLI Commands
- Layer 2/3 Switches & Routers

# Project Highlights

- Designed separate VLANs for each department
- Implemented efficient IP allocation using VLSM
- Configured trunk links for inter-switch communication
- Verified end-to-end connectivity between VLANs

Simulated a real-world corporate network environment

🏁 Outcome

A fully functional simulated network that demonstrates departmental segmentation, optimized IP planning, and secure communication across all areas of GreenSpark Tech.
